# Leave-By Planner

Back-calculate when to walk out the door from appointment + travel + buffers + prep.

**One-liner:** Tell it when you must arrive — it tells you exactly when to start prep and when to leave, with contingency baked in.

## Why it’s useful
People plan arrival time, not departure. This reverses the timeline: prep → leave-by → travel → parking/security → arrive.
